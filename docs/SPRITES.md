# 逐日剑士 Sprite 待机样片

使用现有逐日剑士立绘作为唯一人物参考，通过 ChatGPT 内置 imagegen 生成 4 列 × 2 行的八帧图集。原图与提示词存入 [2026-10-26 运行档案](../assets/daily/2026/10/26/20261026-203035-sprite/manifest.json)，没有修改既有立绘、每日定时规则或固定对照。

启动 `npm run dev` 后打开 [人物动作预览](http://127.0.0.1:4173/demo/sprites.html)。可播放／暂停、逐帧选择、切换 4／8／12 帧每秒，比较深色／浅色／棋盘背景，以及查看整张原图。系统设置“减少动态效果”时默认暂停。页面离线运行，不需要额外软件、MCP 或 API 密钥。

## 素材与配置

- [原始透明 PNG](../assets/daily/2026/10/26/20261026-203035-sprite/library/sunward-idle-sheet.png)：实际 **1448 × 1086**，请求 1024 × 768；保留工具输出的原始字节，不隐瞒尺寸偏差。
- [动画 JSON](../assets/sprites/sunward-idle/animation.json)：默认 8 帧／秒，1 秒循环，按从左到右、从上到下读取。
- 每个源帧为 **362 × 543**。显示画布为 **402 × 583**，四周增加布局留白；这不是新增图像像素。
- 配置中的 `frames[].x/y/w/h` 是原图切帧区域；`drawOffset` 是统一显示留白；`frames[].dx/dy` 是可选的位置对齐。显示时不逐帧缩放、不重绘、不生成中间帧。
- `固定脚底` 将可见较低鞋底的位置对齐至首帧，横向修正 0–21 像素、下排纵向修正 9 像素。关闭即可查看原始漂移。源 PNG 始终不变。

JSON 是本仓库预览器使用的通用帧配置，尚未导出 Cocos、Unity 等引擎专用资源。接入微信小程序时需要按所用渲染器读取切帧区域、位置偏移与帧率；本次没有修改或验证小程序工程。

## 实际效果

八帧均可解码、互不相同，八格人物头脚及长剑轮廓可见；真实 alpha 背景已在深浅底检查。工具图像展示中的大片白色／蓝色剑边底色，在按原 PNG alpha 正常显示时没有相同表现，不把工具展示底色当作实际背景。

这一版可用于观察 AI 图集转为动画的效果，但不是已经精修的上线动作。原始帧存在横向漂移，下排鞋底比上排高 9 像素；位置对齐后，下排人物头顶仍比上排低约 6 像素，说明整体比例并未严格锁定。盔甲纹理、高光及局部姿态变化会产生细微闪烁，八帧未严格实现均匀的呼吸相位，首尾衔接仍有跳变。应在预览中检查后再决定是否制作下一版。

当前只有一个朝向的待机样片，没有走路、攻击、受击或骨骼动画。底层模型版本与随机种子未报告，均按 `unreported`／`null` 记录。

## 验证

`npx playwright test tests/sprites.spec.js` 覆盖真实 PNG／帧区域、按时间换帧、暂停、调速、逐帧选择、透明背景查看、固定脚底开关、下载入口、390px 布局与加载失败重试。另对历史页新增入口和当日 15 张记录进行了只读检查。
