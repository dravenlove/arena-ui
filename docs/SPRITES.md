# 逐日剑士连续待机与八帧对照

人物动作预览默认使用**同一张逐日剑士立绘做连续呼吸**，解决原八帧图集播放时脸部、盔甲纹理和人物比例变化带来的闪烁。实现方式是实时 WebGL 纹理网格变形：持续读取原人物 PNG，轻微移动胸肩区域，保持下肢、长剑和握剑手附近固定。这次没有生成更多 AI 动作帧，没有修改原始 PNG，也不代表新的模型效果。

启动 `npm run dev` 后打开 [人物动作预览](http://127.0.0.1:4173/demo/sprites.html)。在“动作方式”中可以切换“连贯待机 · 单张立绘”和“原始 8 帧 · AI 图集”，直接比较两种方式。旧图集与生成记录继续保留。

## 默认的连续呼吸

连续模式默认 **3.2 秒完成一次呼吸**。胸肩轻微起伏，头部随之轻移；腰以下区域不做位移，剑与握剑手附近通过固定区域保持稳定。人物脸部、盔甲和武器纹理始终来自同一张图，不会在不同 AI 生成帧之间换样。

- “播放／暂停”控制循环播放。
- “呼吸进度”滑块可查看任意相位，拖动后暂停，方便比较静态位置。0% 与 100% 是相同姿态，50% 为吸气峰值。
- “呼吸速度”提供 0.5／1／1.5 倍速，对应每次约 6.4／3.2／2.13 秒。倍速改变播放周期，不增加动作幅度。
- 深色／浅色／棋盘背景用于检查轮廓与透明边缘。“整张图集”仍显示原始八帧图，便于对照。
- 下载入口跟随动作方式切换：连续模式提供原始人物 PNG 和连续动作配置，八帧模式提供原图集和切帧配置。

系统设置“减少动态效果”时默认暂停，可手动播放。页面使用本地素材离线运行；连续模式需要浏览器支持 WebGL，不需要调用图像服务或配置 API 密钥。如果无法创建 WebGL 画布，页面会说明原因并提供原始八帧查看方式。

## 连续动作的文件与接口

| 文件 | 用途 |
| --- | --- |
| [原始人物 PNG](../assets/daily/2026/10/26/20261026-164915-characters/library/sunward-swordsman.png) | 1024 × 1536 的人物纹理，保持原文件不变 |
| [idle-motion.json](../assets/sprites/sunward-idle/idle-motion.json) | 连续呼吸周期、画布、网格、位移和固定区域配置 |
| [idle-motion.js](../demo/idle-motion.js) | WebGL 网格渲染器，暴露 `window.ArenaIdleMotion` |
| [sprites.js](../demo/sprites.js) | 加载素材、播放计时、相位与速度控制、新旧模式切换 |

当前配置为 `mode: procedural`、`renderer: webgl-mesh`，使用 64 列 × 96 行网格，显示画布为 **512 × 768**。纹理坐标始终指向同一张原图；程序根据呼吸相位移动网格顶点，再由 WebGL 绘制画面，原图不被覆盖。

`motion` 中的像素参数以 **1024 × 1536 原图坐标**为单位：胸部提升参数为 10 像素、头部提升参数为 5 像素、胸部扩张参数为 5.5 像素，实际位移还受区域权重影响，并按画布比例缩放。源坐标 `y >= 0.5`，即原图第 768 像素以下的网格顶点固定；当前画布对应第 384 像素以下。长剑及握剑手附近另用胶囊形 `rigidRegions` 约束，边缘平滑过渡到可动区域。

渲染器接口：

```js
// canvas 是目标画布；image 必须已加载完成，尺寸与配置一致。
const renderer = window.ArenaIdleMotion.create(canvas, image, config);
renderer.draw(0);   // 呼气结束
renderer.draw(0.5); // 吸气峰值
renderer.draw(1);   // 回到与 0 相同的姿态
renderer.dispose();
```

`create(canvas, image, config)` 创建纹理和网格，并绘制初始相位；它不负责下载图片或推进时间。调用方按 `cycleSeconds` 和倍速推进相位，再调用 `draw(phase)`；有限相位值会归一化到一个周期。页面使用 `requestAnimationFrame` 推进，标签页隐藏时暂停推进。`dispose()` 释放该实例的 WebGL 纹理、缓冲区和相关资源，释放后不应继续绘制。

连续位移采用余弦周期，整周期首尾姿态一致，接缝处的位移速度也连续。这保证的是程序控制曲线的连续性，不等于已经完成真实人体呼吸或关节绑定制作。

## 原始八帧图集与生成记录

旧样片使用现有逐日剑士立绘作为唯一人物参考，通过 ChatGPT 内置 imagegen 生成 **4 列 × 2 行**的八帧图集。原始提示词、参考图、尺寸和文件哈希保留在 [2026-10-26 运行档案](../assets/daily/2026/10/26/20261026-203035-sprite/manifest.json)。底层模型版本和随机种子未报告，分别记为 `unreported` 和 `null`。没有修改每日定时规则或固定基准题目。

- [原始透明图集 PNG](../assets/daily/2026/10/26/20261026-203035-sprite/library/sunward-idle-sheet.png) 实际为 **1448 × 1086**，请求尺寸为 1024 × 768；保留工具输出原始字节。
- [animation.json](../assets/sprites/sunward-idle/animation.json) 默认 8 帧／秒、1 秒循环，按从左到右、从上到下读取。旧模式仍可切换 4／8／12 帧每秒，逐帧选择或播放。
- 每个源帧为 **362 × 543**，显示画布为 **402 × 583**，通过布局增加四周留白，没有新增或重绘图像像素。
- `frames[].x/y/w/h` 是切帧区域，`drawOffset` 是统一留白，`frames[].dx/dy` 是可选的位置对齐；旧模式不逐帧缩放、不生成中间帧。
- “固定脚底”只调整每帧显示位置，将较低鞋底对齐至首帧：横向修正 0–21 像素，下排纵向修正 9 像素。关闭即可观察原始漂移。

旧八帧可解码且互不相同，但没有严格锁定人物比例和装备细节。脚底对齐后，下排人物头顶仍比上排低约 6 像素；脸、盔甲纹理、高光和局部姿态的变化不能通过平移消除。八帧未严格实现均匀呼吸相位，首尾也有跳变。因此它继续作为生成结果与局限的对照，不作为当前默认待机效果。

旧图集曾按 PNG 原始 alpha 在深浅底检查；工具展示中的大片白色／蓝色剑边底色，在正常 alpha 合成时没有相同表现，不能直接把工具展示底色当作实际背景。

## 复用范围与验证方式

单图变形适合当前这种**幅度很小的待机呼吸**，能够保持人物纹理一致。它没有制作完整骨骼绑定，不会生成被遮挡的身体或新的视角。走路、攻击、受击等动作仍需规范的分层、绑定与动作制作；扩大本配置的位移幅度可能拉伸服装或暴露固定区域附近的变形，不能靠加大数值替代动作设计。

当前只有一个人物、一个朝向的浏览器预览。尚未导出引擎专用资源，也**未在微信小程序工程中实装或实机验证**；后续需按小程序实际渲染环境处理图片加载、WebGL 画布、相位计时与资源释放，不能把本页可运行当作已完成接入。

2026-10-27 运行 `npx playwright test tests/sprites.spec.js --workers=2`，10 项检查全部通过，覆盖相位推进、暂停、调速、首尾像素一致、脚部固定、新旧切换、390px 手机布局及 WebGL 不可用时的回退。旧模式保留切帧、透明背景查看与对齐开关检查。另检查了深浅背景与呼吸各相位的画面；这些结果仅针对浏览器预览。
