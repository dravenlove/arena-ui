## 预览与接入

预览页通过坐标在浏览器中显示单个格子，**不改写原图、不额外生成裁切文件**。支持分类筛选、深浅底和中文叠字示意；可展开全图或下载原始PNG。`assets/anime-ui.json` 的每个 `rect` 使用实际 PNG 像素坐标，包含透明留白；不是物体的紧贴边界，也不是九宫格拉伸参数。

- 小程序可按坐标通过 Canvas 取图，或将原图放入固定大小、隐藏溢出的容器定位显示；文字和数值用实际控件覆盖。需要独立小图时再按记录导出，不覆盖原始图集。
- 按钮状态之间的装饰和位置略有差异，切换时可能出现轻微跳动；建议接入前统一热区与锚点。
- 面板中间已有填色，适合作为底板。若要任意拉伸，需要另行确定九宫格边距并处理分割线，当前没有验证九宫格参数。
- HP、能量、经验条约为70%、50%、40%填充；星级为三实二空。它们已画入图片，需要拆分边框／填充或用代码绘制才能随数值变化。专页中文数值只是叠字示例。
- 导航外框接近各自格子边缘，留白小于提示要求；细节较多，小尺寸保留文字标签。先在预览里检查，再按目标设备确定显示尺寸。

## 文件检查与可见偏差

四张都可解码且具有真实透明通道，原图按工具输出字节保存。按钮、导航、养成图集 alpha 范围为 **0–254**；面板为 **0–255**。完全透明像素分别约 **57.5%、64.6%、55.7%、29.0%**。面板请求1024×1024，实际1254×1254，其他三张实际与请求均为1536×1024。
