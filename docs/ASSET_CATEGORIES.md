## 分类规则

按主要复用用途给每个素材一个分类。多用途素材选择当前最明确的展示场景，例如胜利奖杯归“状态反馈”，地城钥匙归“养成与奖励”。包含多个物件的原始图集整体归类，未额外裁切成独立文件。

风格、用途与实验身份是三个独立维度：[风格目录](STYLES.md)明确区分二次元奇幻、Q版奇幻与深色金属。筛选按三者与日期取交集。装备图集属于“武器防具”，同时属于“固定对照”；独立手弩属于“武器防具”，同时属于“素材扩展”。分类数量跟随所选日期和实验分组变化。

原图仍在原来的按日期归档目录，文件名、原始提示词、校验值和历史运行清单保持原样。类别目录位于 [assets/categories.json](../assets/categories.json)，通过 `assetCategories[asset.id]` 映射用途；相同素材 ID 的不同日期样本自动使用同一分类。

## 新素材如何登记

1. 在原日期目录保存素材，并照常写入运行清单与每日索引。
2. 检查 `assets/categories.json` 中是否已有该 `asset.id`，有则复用；没有则按主要用途补一条映射。
3. 新分类应同时加入 `categories` 的 ID、中文名称和简短用途说明。不要使用保留 ID `all` 或 `uncategorized`。
4. 提交本次素材时一并提交有关的分类映射。

页面会把未登记的未来素材显示为“待分类”，保留原图和日期筛选，不会丢失或根据运行主题误分类。分类目录暂时加载失败时，所有素材也能按日期访问。

分类文件完整性、跨日筛选、日期／实验分组交集、空结果、未知素材和分类加载失败，以及 390px 布局与键盘操作，均由 `tests/history.spec.js` 验证。
